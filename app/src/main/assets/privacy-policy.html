PRIVACY POLICY - MTS dialer (cz.mts.phone)

Last updated: 16.09.2026

This application serves as the default phone application (dialer). We respect user privacy and handle sensitive data only to the extent necessary to provide basic calling functionality.

What permissions and data does the application use?

The application requires the following Android system permissions, because they are necessary for its core function as a phone dialer:

  • Contacts (READ_CONTACTS) – to display contact names and allow calling them.
  • Phone / calls (CALL_PHONE, READ_CALL_LOG, READ_PHONE_STATE) – to make calls and display call history.
  • Device phone number – only if required by system functions (e.g. setting the default calling app).
  • Sending SMS (SEND_SMS) – only if the user declines an incoming call with the option to send the caller an automatic SMS message.

None of this data is collected or stored by the application outside the user's device.

How do we handle data?

The application:

  • does not store any data on external servers,
  • does not share any data with third parties,
  • does not send any information outside the device,
  • does not contain analytics tools or advertising,
  • works only with data stored on the device and only within the scope of providing calling functions.

All data the application has access to remains exclusively on the user's device and is removed from it upon uninstallation of the application.

Security

The application does not transmit any data outside the device, so no leak can occur through the application itself. The security of data stored on the device is handled by the Android system.

Children

The application does not collect, store, or transmit any personal data outside the device, and is therefore also suitable for younger users. The application is not specifically targeted at children, but since it does not process any data outside the device, it poses no risk in terms of children's privacy protection.

Changes to this policy

If changes to the application's functions occur that would require handling data in a different way, this policy will be updated and the new version will be published on this page, stating the date of the last update.

ZÁSADY OCHRANY SOUKROMÍ - cz.mts.phone

Poslední aktualizace: 16.09.2026

Tato aplikace slouží jako výchozí telefonní aplikace (dialer). Respektujeme soukromí uživatelů a s citlivými údaji zacházíme pouze v rozsahu nezbytném pro poskytování základních funkcí volání.

Jaká oprávnění a údaje aplikace využívá?

Aplikace vyžaduje následující oprávnění systému Android, protože jsou nutná pro její základní funkci telefonního dialeru:

  • Kontakty (READ_CONTACTS) – pro zobrazení jmen ke kontaktům a možnost jim volat.
  • Telefon / hovory (CALL_PHONE, READ_CALL_LOG, READ_PHONE_STATE) – pro uskutečňování hovorů a zobrazení historie hovorů.
  • Telefonní číslo zařízení – pouze pokud to vyžadují systémové funkce (např. nastavení výchozí aplikace pro volání).
  • Odesílání SMS (SEND_SMS) – pouze pokud uživatel odmítne příchozí hovor s možností odeslat volajícímu automatickou SMS zprávu.

Žádné z těchto údajů aplikace neshromažďuje ani neukládá mimo zařízení uživatele.

Jak s údaji nakládáme?

Aplikace:

  • neukládá žádné údaje na externí servery,
  • nesdílí žádné údaje s třetími stranami,
  • neodesílá žádné informace mimo zařízení,
  • neobsahuje analytické nástroje ani reklamy,
  • pracuje pouze s daty uloženými v zařízení a pouze v rámci poskytování funkcí volání.

Veškeré údaje, ke kterým má aplikace přístup, zůstávají výhradně na zařízení uživatele a jsou z něj odstraněny při odinstalaci aplikace.

Bezpečnost

Aplikace nepřenáší žádná data mimo zařízení, a proto nemůže dojít k jejich úniku prostřednictvím aplikace samotné. O bezpečnost dat uložených v zařízení se stará systém Android.

Děti

Aplikace neshromažďuje, neukládá ani nepředává žádné osobní údaje mimo zařízení, a proto je vhodná i pro mladší uživatele. Aplikace není cíleně zaměřena na děti, ale vzhledem k tomu, že nezpracovává žádná data mimo zařízení, nepředstavuje z hlediska ochrany soukromí dětí žádné riziko.

Změny těchto zásad

V případě, že dojde ke změnám funkcí aplikace, které by vyžadovaly práci s daty jiným způsobem, budou tyto zásady aktualizovány a nová verze bude zveřejněna na této stránce s uvedením data poslední aktualizace.

隐私政策 - MTS 拨号器 (cz.mts.phone)

最后更新日期:2026年09月16日

本应用程序作为默认电话应用程序(拨号器)使用。我们尊重用户隐私,仅在提供基本通话功能所必需的范围内处理敏感数据。

应用程序使用哪些权限和数据?

本应用程序需要以下 Android 系统权限,因为这些权限是其作为电话拨号器核心功能所必需的:

  • 通讯录(READ_CONTACTS) – 用于显示联系人姓名并拨打电话。
  • 电话/通话(CALL_PHONE、READ_CALL_LOG、READ_PHONE_STATE) – 用于拨打电话和显示通话记录。
  • 设备电话号码 – 仅在系统功能需要时使用(例如设置默认通话应用程序)。
  • 发送短信(SEND_SMS) – 仅当用户拒接来电并选择向来电者发送自动短信时使用。

应用程序不会在用户设备之外收集或存储上述任何数据。

我们如何处理数据?

本应用程序:

  • 不会将任何数据存储在外部服务器上,
  • 不会与第三方共享任何数据,
  • 不会将任何信息发送到设备之外,
  • 不包含分析工具或广告,
  • 仅处理存储在设备上的数据,且仅在提供通话功能的范围内使用。

应用程序可访问的所有数据均仅保留在用户设备上,并在卸载应用程序时从设备中删除。

安全性

本应用程序不会将任何数据传输到设备之外,因此不会通过应用程序本身发生数据泄露。设备上存储数据的安全性由 Android 系统负责。

儿童

本应用程序不会收集、存储或向设备之外传输任何个人数据,因此也适合较年轻的用户使用。本应用程序并非专门针对儿童设计,但由于其不处理设备之外的任何数据,因此在儿童隐私保护方面不构成任何风险。

政策变更

如果应用程序的功能发生变化,需要以不同方式处理数据,本政策将会更新,新版本将发布在本页面上,并注明最后更新日期。

私隱政策 - MTS 撥號器 (cz.mts.phone)

最後更新日期:2026年09月16日

本應用程式作為預設電話應用程式(撥號器)使用。我們尊重用戶私隱,僅在提供基本通話功能所必需的範圍內處理敏感資料。

應用程式使用哪些權限和資料?

本應用程式需要以下 Android 系統權限,因為這些權限是其作為電話撥號器核心功能所必需的:

  • 聯絡人(READ_CONTACTS) – 用於顯示聯絡人姓名並致電。
  • 電話/通話(CALL_PHONE、READ_CALL_LOG、READ_PHONE_STATE) – 用於撥打電話及顯示通話記錄。
  • 裝置電話號碼 – 僅在系統功能需要時使用(例如設定預設通話應用程式)。
  • 傳送短訊(SEND_SMS) – 僅當用戶拒接來電並選擇向來電者傳送自動短訊時使用。

應用程式不會在用戶裝置之外收集或儲存上述任何資料。

我們如何處理資料?

本應用程式:

  • 不會將任何資料儲存在外部伺服器上,
  • 不會與第三方分享任何資料,
  • 不會將任何資訊傳送到裝置之外,
  • 不包含分析工具或廣告,
  • 僅處理儲存在裝置上的資料,且僅在提供通話功能的範圍內使用。

應用程式可存取的所有資料均只保留在用戶裝置上,並在解除安裝應用程式時從裝置中刪除。

安全性

本應用程式不會將任何資料傳輸到裝置之外,因此不會透過應用程式本身發生資料外洩。裝置上儲存資料的安全性由 Android 系統負責。

兒童

本應用程式不會收集、儲存或向裝置之外傳輸任何個人資料,因此亦適合較年輕的用戶使用。本應用程式並非專門針對兒童設計,但由於其不處理裝置之外的任何資料,因此在兒童私隱保護方面不構成任何風險。

政策變更

如應用程式的功能發生變化,需要以不同方式處理資料,本政策將會更新,新版本將發佈在本頁面上,並註明最後更新日期。
