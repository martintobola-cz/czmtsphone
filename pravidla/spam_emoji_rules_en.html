Rules

  1. Saved contact = contact found in CacheContacts. CNAP is ignored, no spam check runs.
  2. Unsaved contact: name = CNAP > number > R.string.unknown_caller.
  3. A CNAP identical to the number (after normalizeDigitsOnly) is treated as if there were no CNAP.
  4. Hidden number = number is missing (empty, handle null, or handle other than tel:, e.g. sip:). With presentation 2/3 but a number in the handle, the number is used (not "unknown"). The distinction between presentation 2/3/4 is not used.
  5. The spam check runs only for an incoming call, an unsaved contact, a known number, and CacheContacts.bSpamChecking == true.
  6. Spam = bSpamCallfilterApp || bSpam.
  7. State "waiting" = emoji is empty (result has not arrived yet). For #6 the number is shown (clickable), for #8 the number on row 2; no emoji.
  8. State "error" = result.ok == false, empty/mismatching number (∅😕, ≠😕), or the getCallFilterInfo callback returns null (exception etc.). 💥😕 is shown, also in the notification.
  9. #4 and #5: row 2 is governed by bSpamChecking and the presence of CNAP (not by CallEntry.isSpam). Row 2 is not clickable because it is not a number.
  10. Notification: never contains R.string.is_spam_call; title = [emoji] name · number; when space is short, the number is truncated (the name has priority).
  11. The watch uses the same title as the notification; text = SIM + state (unchanged).
  12. The rating emoji in the notification title is at the beginning so truncation does not cut it off.

Implementation notes (from code analysis)

  • CNAP is currently stored in CallEntry.cnapName but is not used anywhere.
  • Later: extend CallEntry with getCallerNumberVerificationStatus() (API 30+; default value on API 28–29). Not used for now.
  • call.details.contactDisplayName is NOT used (the source of truth is CacheContacts).
  • With an empty number, getCallContact currently hard-codes presentation = 3 – replace it with a "hidden" flag and a CNAP item.
  • Hidden number (isHiddenNumber) is governed by an empty number – this changes the SMS button and the anonymous avatar for presentation 2/3 with a number.
  • CallManager.onCallAdded: when result == null, nothing is written today; newly write emoji = 💥😕, isSpam = false and call the listener.
