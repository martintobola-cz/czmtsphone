PRAVIDLA
---------------------------------------------------------------------------
1. Ulozeny kontakt = kontakt nalezeny v CacheContacts. CNAP se ignoruje, spamcheck neprobehne.
2. Neulozeny kontakt: jmeno = CNAP > cislo > R.string.unknown_caller
3. CNAP shodny s cislem (po normalizeDigitsOnly) se bere, jako by CNAP nebyl.
4. Skryte cislo = cislo chybi (prazdne, handle null nebo handle jiny nez tel:, napr. sip:).
   Pri presentation 2/3, ale s cislem v handle, se pracuje s cislem (neni "neznamy").
   Rozliseni presentation 2/3/4 se nepouziva.
5. Spamcheck bezi jen pro prichozi hovor, neulozeny kontakt, znamé cislo a
   CacheContacts.bSpamChecking == true.
6. Spam = bSpamCallfilterApp || bSpam.
   Oprava v checkNumberForRating:
   return if (!bRecent) RatingResult(sRetText, bSpamCallfilterApp || bSpam)
7. Stav "ceka" = emoji je prazdne (vysledek jeste neprisel). U #6 se zobrazi cislo
   (klikatelne), u #8 cislo na radku 2; zadne emoji.
8. Stav "chyba" = result.ok == false, prazdne/nesouhlasici cislo (∅😕, ≠😕),
   nebo callback getCallFilterInfo vrati null (vyjimka apod.). Zobrazi se 💥😕
   i v notifikaci.
9. #4 a #5: radek 2 se ridi bSpamChecking a pritomnosti CNAP (nejde o CallEntry.isSpam).
   Radek 2 neni klikatelny, protoze neni cislo.
10. Notifikace: nikdy neobsahuje *R.string.is_spam_call*; titulek = [emoji] jmeno · cislo;
    pri nedostatku mista se orizne cislo (jmeno ma prednost).
11. Hodinky pouzivaji stejny titulek jako notifikace; text = SIM + stav (beze zmeny).
12. Rating emoji v titulku notifikace je na zacatku, aby ho zkraceni neodriznulo.


POZNAMKY K IMPLEMENTACI (z analyzy kodu)
---------------------------------------------------------------------------
- CNAP je dnes ulozen v CallEntry.cnapName, ale nikde se nepouziva.
- Pozdeji: CallEntry rozsirit o getCallerNumberVerificationStatus() (API 30+,
  na API 28-29 vychozi hodnota). Zatim se nepouzije.
- call.details.contactDisplayName se NEPOUZIVA (pravda je CacheContacts).
- getCallContact dnes pri prazdnem cisle natvrdo vraci presentation = 3 -
  nahradit priznakem "skryte" a polozkou CNAP.
- Skryte cislo (isHiddenNumber) se ridi prazdnym cislem - zmeni se SMS tlacitko
  a anonymni avatar u presentation 2/3 s cislem.
- CallManager.onCallAdded: pri result == null dnes nic nezapise; nove zapsat
  emoji = 💥😕, isSpam = false a zavolat listener.
